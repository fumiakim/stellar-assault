# STELLAR ASSAULT ─ 縦スクロールシューティング

全5面・各面ボス戦つき・2人同時プレイ対応の縦スクロールシューティングゲームです。
HTML5 Canvas と WebAudio だけで作られており、外部ライブラリ・画像・音声ファイルは一切使いません。

## 遊び方

`index.html` をブラウザ（Chrome / Safari / Edge など）で開くだけです。ダブルクリックでも動きます。

```bash
open index.html
```

音が出ない場合は、一度どれかキーを押してください（ブラウザの自動再生制限のため、初回のキー入力で音声が有効になります）。

## 操作

| | 1P | 2P |
|---|---|---|
| 移動 | `W` `A` `S` `D` | `↑` `↓` `←` `→` |
| ショット | `Space` | `Enter` / テンキー `0` |
| ボム | `Q` / 左`Shift` | `/` / 右`Shift` / テンキー `.` |

- ショットは押しっぱなしで連射されます。
- `P`（または `Esc`）で一時停止、`M` でサウンドの ON/OFF。
- タイトル画面：`W`/`S`・`↑`/`↓` で項目選択、`A`/`D`・`←`/`→` で変更、`Space`/`Enter` で決定。

### ゲームパッド（1P）

**1P はゲームパッドでも操作できます。** 標準マッピング（Xbox / PlayStation / Switch Pro など、
ブラウザが `standard` として認識するコントローラ）に対応しています。

| | 割り当て |
|---|---|
| 移動 | 左スティック（アナログ）／ 十字キー |
| ショット | `A` `X` `R1` `R2` |
| ボム | `B` `Y` `L1` `L2` |
| 一時停止 | `START` |
| メニュー | 十字・左スティックで選択、`A` / `START` で決定 |

- 接続後、**ボタンを1回押す**とブラウザがパッドを認識します。認識されるとタイトル画面に
  コントローラ名が緑色で表示されます。
- 左スティックはアナログ入力で、倒し具合に応じて移動速度が変わります（微調整が可能）。
- キーボードと同時に使えます。2P はキーボード専用です。
- サウンドはブラウザの制限により、パッドだけでは有効にならない場合があります。
  音が出ないときはキーボードのキーを一度押してください。

## 2人同時プレイ

- タイトルの「プレイ人数」で **2人同時プレイ** を選ぶと最初から2人で始められます。
- 1人で始めた場合でも、**ゲーム中に2Pのショットボタンを押せばいつでも途中参加**できます。
- 残機・ボム・パワー・スコアはプレイヤーごとに独立しています。
- 残機が尽きたプレイヤーには10秒のカウントダウンが出ます。ショットボタンでコンティニュー（回数無制限）。
  片方が生きている間はゲームは続き、後からいつでも復帰できます。両者が復帰しないまま時間切れになるとゲームオーバーです。
- 2人プレイ時は敵とボスの耐久力が上がります（雑魚 ×1.45／ボス ×1.75）。

## ステージ構成

| 面 | ステージ | ボス |
|---|---|---|
| 1 | 蒼空突破 | 大型爆撃機 **ヴァルキリー** |
| 2 | 蒼海の防衛線 | 航空戦艦 **ポセイドン**（主砲2基が破壊可能） |
| 3 | 紅蓮の峡谷 | 機甲蟲 **スカラベ**（突進＋機雷） |
| 4 | 夜間都市強襲 | 巨大機兵 **ゴライアス**（両腕が破壊可能・レーザー） |
| 5 | 最終要塞 オメガ | 最終要塞核 **オメガ**（衛星4基・4段階変形） |

各ボスは体力に応じて攻撃パターンが変化します（1〜4段階）。段階が変わるときは画面上の敵弾が消えます。

タイトルの「開始ステージ」で任意の面から始められるので、好きな面のボスだけ練習することもできます。

### 難易度の傾き

面ごとに「弾の密度」を設定しており、発射間隔・一度に撒く弾数・弾速がまとめて変化します。
1面はかなり控えめで、5面で最大になります。1面は序盤に撃ってくる敵を置かず、
まず自機の操作と火力に慣れられる構成にしています。

- 発射頻度は全体に `FIRE_RATE`（既定 0.5）倍。面ごとの `dens` と掛け合わされます。
- 雑魚（`pop`）と機雷（`mine`）は `weak` 指定で、面や人数によるHP補正を受けず**常に1発で撃墜**できます。
- 敵弾は生成時に半径を 0.9 倍しています（見た目と当たり判定の両方）。
- 各面の `dim` で背景に暗幕を重ね、自機・敵・弾が背景に埋もれないようにしています。
- 機雷は**撃ち落とせば安全**で、放置して時間切れ自爆したときだけ弾を撒きます。

もっと簡単／難しくしたい場合は、`index.html` 内の `FIRE_RATE` と各ステージの `dens` を変えるだけで調整できます。

## 自機のパワーアップ

**レーザー1本**から始まり、`P` アイテムを取るたびに強化されていきます。最大は **P4** です。

| Lv | 効果 |
|---|---|
| **P0** | 中央レーザー1本（初期状態） |
| **P1** | ＋ 自機の移動速度アップ（3.6 → 4.6 px/フレーム） |
| **P2** | ＋ 直進ショット2発 |
| **P3** | ＋ 斜めショット2発（連射も速くなる） |
| **P4** | 中央レーザーが大幅に強化 |

撃墜されるとパワーが1段階下がり、お詫びに `P` アイテムが1つ出ます。

## アイテム

| | 効果 |
|---|---|
| **P** | パワーアップ（最大 P4） |
| **B** | ボム +1（最大6） |
| **S** | 得点 500 |
| **1** | 1UP（残機 +1） |

1面には敵を倒さなくても手に入る補給アイテムが上空から降ってきます。
雑魚からのランダムドロップは 7%（`takeItem` 付近の判定値）です。

## スコア

- 敵の撃破点、ボスへの与ダメージ、破壊可能パーツの撃破ボーナス
- ステージクリアボーナス＝ 残機×10,000 ＋ ボム×4,000 ＋ 面数×20,000
- ボス撃破ボーナス＝ 50,000〜250,000（面が進むほど高い）
- 全面クリア時、コンティニュー0回なら評価 **S**

## グラフィック素材

自機の絵は [Replicate](https://replicate.com) の `black-forest-labs/flux-schnell` で生成しました。

| ファイル | 内容 |
|---|---|
| `art/p1-a0.png` 〜 `p1-a3.png` | 生成された4案（1024×1024） |
| `art/p1-contact.png` | 4案の比較シート（原画とゲーム内サイズ） |
| `art/ship-1p.png` | 採用した A案から作った透過スプライト（256×158） |
| `art/make-sprite.py` | `p1-a0.png` から `ship-1p.png` を作り直すスクリプト |

- 2P機は同じ画像の**色相だけを差し替えて**オレンジにしています（Canvas の `hue` 合成）。
  白い機体はそのままで、青い翼だけがオレンジになります。
- エンジンの炎はスプライトに焼き込まず、これまでどおり毎フレーム揺らして描いています。
- **`art/ship-1p.png` が読み込めない場合は、従来の Canvas パス描画に自動でフォールバック**します。
  `index.html` を単体で持ち出しても、絵は素朴になりますがゲームは問題なく動きます。

生成に使ったプロンプト（要点）:

> Top-down view of a small futuristic fighter spacecraft seen from directly above,
> nose pointing straight up, perfectly bilaterally symmetrical, swept-back delta wings,
> glossy white hull with deep blue wing panels, glowing cyan cockpit canopy,
> twin cyan engine flames trailing downward, retro arcade vertical shoot-em-up game sprite,
> bold clean silhouette, crisp hard edges, flat even lighting, centered,
> isolated on pure flat black background

背景を純黒にしておくと、外周からのフラッドフィルで確実に切り抜けます（AIの背景除去は炎のグローを削りがちなため）。

## 技術メモ

- 単一ファイル（`index.html`、約2,300行）。ビルド不要・依存なし。
- 論理解像度 480×640 を CSS transform でウィンドウに合わせて拡大。
- 固定タイムステップ 60fps（1フレームあたり最大4回まで追いつき処理）。
- BGM は WebAudio のオシレータによるコード進行ベースの簡易シーケンサ、効果音もすべて合成。
- 背景は5面それぞれ手続き的に描画（雲・海と島・峡谷・夜の街・宇宙要塞）。
